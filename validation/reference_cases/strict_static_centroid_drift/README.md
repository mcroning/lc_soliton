# strict_static_centroid_drift

Short strict-static reference case.

This case is used as an early physics-regression fingerprint. It is intentionally
small enough to rerun quickly, but nontrivial enough to produce measurable
centroid drift.

Reference metrics:

- max |xc| = 8.22930613823403e-06 um
- rms xc = 5.67690474950173e-06 um
- approximate runtime = 6 seconds

Large raw run outputs are not committed.
