# lc-soliton examples

This directory will contain reproducible example scripts and notebooks for:

- static LC propagation
- time-dependent relaxation
- eigensoliton continuation
- stability analysis
- run loading and visualization

The examples are intended to reproduce validated research workflows with minimal setup.

## Existing run reload

Example script:

    python examples/load_existing_run.py

Edit the RUN_DIR variable to point to a saved run directory containing
metadata.json and reproducibility files.
